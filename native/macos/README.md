# Xtranslate · macOS 原生社区移植

[English](README.en.md) · [上游项目](https://github.com/hopechen067/Xtranslate) · [社区安装包](https://github.com/xyxxxx06221/Xtranslate/releases/tag/macos-native-v1.1.1)

这是基于 [hopechen067/Xtranslate](https://github.com/hopechen067/Xtranslate) 的**非官方社区 macOS 移植**，不是上游官方 macOS 发行版，也不代表此贡献已被上游采纳。原项目的交互思路、翻译提示词和服务商预设沿用并适配；界面、网络请求、快捷键和粘贴功能使用 Swift、AppKit 与 macOS 系统组件重新实现，不打包 Electron、浏览器内核或本地模型。

支持 **Apple Silicon Mac，macOS 13 或更高版本**。当前构建脚本生成 arm64 应用，不包含 Intel 版本。

## 安装与使用

1. 从上述**社区安装包**页面下载 DMG，将 `Xtranslate.app` 拖到“应用程序”。更新前先退出正在运行的旧版。
2. 打开应用，在“系统设置 → 隐私与安全性 → 辅助功能”中允许当前版本的 Xtranslate。
3. 先点击需要输入文字的目标输入框，再按 **Option+Q** 呼出翻译浮窗。输入文字，按回车翻译并粘贴。

浮窗可拖动边缘缩放并记住大小；圆角背景使用透明遮罩。`Shift+回车` 换行，`Tab` 切换翻译方向，`Command+E` 切换翻译引擎，`Esc` 关闭。快捷键可在设置中修改。

设置中的免费翻译不需要 API Key。使用大模型时，选择服务商、填写服务地址和 API Key，再选择或手动输入模型名称。打开大模型设置、切换服务商或结束地址/密钥编辑后会尝试获取模型，也可点击“刷新模型”。获取不会覆盖已经输入的模型名称；接口不支持列出模型时仍可手动填写。模型列表来自服务商，列表中的模型不一定都支持文字翻译。

## 自动粘贴与权限

应用在呼出浮窗前记录目标应用和可访问的输入窗口/控件，粘贴前重新激活并检查目标，等待快捷键松开，再向目标应用发送粘贴按键。部分应用不暴露完整的辅助功能信息；安全键盘输入、权限或焦点异常也可能阻止自动粘贴。

自动粘贴失败时会显示原因，并尽可能保留译文供手动 `Command+V`。启用“粘贴后恢复原来的剪贴板”时，应用延迟恢复旧剪贴板；如果期间其他应用已更新剪贴板，则不会覆盖新内容。

社区包使用 **ad-hoc 本地签名，未经 Apple 公证**。如 macOS 拦截，请核对下载来源后，在“隐私与安全性”中允许打开。更新会改变应用签名，可能需要移除旧的辅助功能条目、重新添加“应用程序”中的新版，再退出并重新打开应用。设置页会显示当前运行应用的路径及权限状态，便于识别仍在运行的旧副本。

## 数据与服务

- 保存的 API Key 存在本机系统钥匙串中，按服务商与服务地址区分；获取模型或翻译时会将认证信息发送到所配置的服务。
- **原文会发送给你所选择的翻译服务商**。使用大模型翻译不等于离线运行；只有自行配置的本地服务可以在本机处理请求。
- 模型获取支持兼容 `/models` 的接口、Claude 分页，以及本机 Ollama。OpenRouter 的公开模型目录无需 Key；不支持列出模型的服务可以手动配置。
- 免费翻译使用非官方网页接口，可能因服务变更、限流或地区网络条件失效。服务商的模型可用性、费用、数据处理政策与使用条款由该服务商决定。

## 从源码构建

需要 Apple Silicon Mac、Xcode Command Line Tools，以及用于本地测试的 Python 3。先安装命令行工具：

```sh
xcode-select --install
```

在包含此贡献的仓库检出目录中运行：

```sh
cd native/macos
./scripts/build.sh
./scripts/package.sh
```

应用生成于 `build/Xtranslate.app`；安装包生成于 `build/Xtranslate-Native-1.1.1-arm64.dmg`。打包脚本会再次构建并检查本地签名及磁盘映像。无需 npm 或第三方运行时依赖。可以按这些脚本从源码重新构建，但不承诺不同机器生成的二进制逐字节一致。

## 验证

以下默认测试只使用本地样例和回环网络服务，不读取真实 API Key，不访问外部翻译 API：

```sh
./scripts/test-translation.sh     # 45 项翻译解析与请求测试
./scripts/test-model-catalog.sh   # 52 项模型目录测试
```

它们覆盖格式解析、取消、错误处理，以及模型分页、认证请求头、跨源跳转防护等行为。结果不代表所有服务商均已用真实账号验证。

可选的 macOS 界面与系统集成检查：

```sh
./scripts/test-ui.sh
./scripts/test-system.sh
./scripts/test-system-live.sh
```

这些检查需要可用的图形桌面会话。系统测试会临时修改剪贴板，并在正常结束时恢复；运行期间请避免同时复制重要内容。`test-system-live.sh` 会操作专用测试窗口并发送按键，需要相关测试进程的辅助功能/事件发送权限；这里的 “live” 指实际系统交互，不是调用付费模型。

另外，`test-translation.sh --live` 和 `test-model-catalog.sh --live` 会分别访问免费翻译接口、OpenRouter 公开模型目录。这些可选联网检查不需要真实 API Key，也不调用付费模型推理。
